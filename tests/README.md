# Тесты кита

Для первого запуска установите Chromium. Все проверки запускаются через Playwright.

```sh
npx playwright install chromium
npm test
```

`npm test` собирает стенд в `build/playwright` и запускает проверки логики и браузерные сценарии. `npm run test:e2e` запускает только браузерные сценарии. Скриншоты и трассировки упавших тестов сохраняются в `test-results`.

Для интерактивного запуска и отладки браузерных сценариев используйте `npm run test:e2e:ui`. Команда соберёт стенд и откроет интерфейс Playwright.

## Отдельные проверки

```sh
npx playwright test --project=unit
npx playwright test --project=unit api-error-notifications
npm run test:e2e -- variable-list
```

Проект `unit` проверяет формы, фильтры, права меню, загрузку редактора пользователя и уведомления об ошибках. Эти тесты выполняются в Node.js без запуска браузера. В тестах уведомлений реальные Axios-interceptors и RTK Query получают фиктивные ошибки через адаптер без HTTP.

Браузерные сценарии проверяют меню, прокрутку, таблицы и ключевые операции. Набор `full-app` монтирует конфигурацию маршрутов приложения и проверяет прямые переходы, возврат с экрана ошибки, вход и выход, OAuth, профиль, Git, доступы, Swagger и сохранение данных. Отдельно проверяются редактирование ключа в форме конфигурации, повтор сохранения после ошибки и переходы между режимами редактора.

```sh
npm run test:e2e -- full-app
```

Стенд использует фиктивные данные и блокирует сетевые запросы. В сценариях `full-app` работают реальные компоненты формы, JSON-дерева и редактора кода. Интерфейс Monaco и рендерер ReDoc подменены. Для общего лейаута и конфигураций предусмотрены проверки светлой и тёмной тем и разных размеров экрана.

## Проверка соседнего isp-ui-kit

По умолчанию используется установленный `isp-ui-kit`. Для проверки `LayoutMenu` и `Column` из соседнего репозитория соберите стенд с его исходниками и запустите нужные сценарии:

```sh
node tests/build-layout-test.mjs build/playwright ../isp-ui-kit
npx playwright test --project=regression menu column-scroll modules
```

Для ручной проверки можно открыть `build/playwright/layout.html` в браузере. В консоли `window.layoutTest.show('/users/new', true)` открывает экран в тёмной теме. Третий аргумент `false` обновляет данные без пересоздания формы. `window.layoutTest.check()` проверяет размеры и локальную прокрутку.
